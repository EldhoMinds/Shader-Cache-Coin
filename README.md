## 📖 What is Shader Cache Coin?

**Shader Cache Coin (SCC)** is a proof-of-work system that mines prime numbers from existing GPU shader cache files. Instead of wasting electricity on arbitrary hashing, SCC repurposes the shader caches generated by games like **CS2, Valorant, Apex Legends**, and other modern titles.

The protocol extracts 32-bit integers from cache binaries, tests them for primality using optimized algorithms, and assembles them into verifiable **linked list tables**. Each complete table contains **10 million verified primes**.
